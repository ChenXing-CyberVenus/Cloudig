# Cloudig: A tool for exporting, reading and managing AI web conversations

## Download

**[Download V1.0.3 DawnGlow · Windows x64](https://github.com/ChenXing-CyberVenus/Cloudig/releases/download/v1.0.3/Cloudig-1.0.3-Setup.exe)**

Install it in a folder you can write to. Do not choose Program Files.

Cloudig is a complete portable folder: copy it to back it up, move it to relocate it, and delete it to uninstall it. **Note: back up the data inside first.**

Microsoft Edge WebView2 Runtime is required. The installer will prompt you if it is missing.

## About Cloudig

**[Online documentation and platform examples](https://chenxing-cybervenus.github.io/Cloudig/)** · Chinese and English

**Install bookmarklets → Save conversations → Parse → Read**

Bring conversations from AI platforms back to your own computer, preserving thoughts, tool calls, formulas and branches in full, and organize them into works you can read, edit and reuse.

Supports ChatGPT, Claude, Gemini, DeepSeek, Grok, Doubao, Kimi, Qwen, ChatGLM, Z.ai, Yuanbao and Mistral, with ongoing expansion and long-term maintenance.

## V1.0 features

- Archiver: install and update bookmarklets, import HTML and supported JSON, parse and manage archives. Export conversations as Markdown.
- Reader: read conversations, branches, thoughts and tool calls, as well as formulas, diagrams and resources. Supports rendering Claude Cards and Artifacts.
- Search across conversations.
- Independent data standards: Conversation, Mark, Identity, ContentTime and Library; original conversations and your edits are stored separately.
- Content time: mark when a conversation's subject takes place, from the Big Bang to time systems you create yourself.
- Two themes and two languages: Dawn / StarNight, Chinese / English.
- The application includes usage guides, Cloudig Standards, History and Future, and licenses; platform examples can be viewed online or downloaded on demand.

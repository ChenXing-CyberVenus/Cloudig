# 采云书签指南

采云书签用于导出网页端的AI对话，生成可直接阅读的HTML。
V1.0自动安装仅支持Chrome浏览器。

## 极简使用方法：

1. 关闭Chrome浏览器<br>
   若选择使用采云自动安装、更新、卸载书签，请完全退出 Chrome。
2. 选择书签类型，安装书签。<br>
   日常使用轻装；要全附件用全量；要全分支用整树。
3. 用chrome打开AI平台会话
4. 点击书签，耐心等待导出完成<br>
   当导出会话时，请保持正在导出的页面标签页持续处于前台可见状态，不要操作页面，直到 HTML 出现在下载列表。
5. 检查HTML文本、格式与文件
6. 如有文本、图片或文件缺失：
   1. 检查使用的书签版本。<br>
      轻装Light版仅导出页面文字与压缩图片，不包含用户上传的附件文本与AI生成的文件。
   2. 刷新页面，按需选择书签版本再次下载文件——网络波动、服务器状态有时会导致内容缺失。

   如检查以上两步后问题未解决，请打开采云档案馆右侧边栏的系统日志，找到相应错误信息，复制，带版本、日志、截图和去敏页面联系作者。
7. 保留原始HTML，它是以后采云重新解析的来源。

## 一、书签类型

| 书签类型 | 保存范围 | 图片与文件 |
|---|---|---|
| 轻装Light | 当前分支 | 压缩图片，其他文件只保留名称 |
| 全量Full | 当前分支 | 原始图片与完整附件 |
| 整树Tree | 完整消息树 | 同全量 |

日常使用可选择轻装，以节省存储空间；<br>
三类书签可同时安装，按需采集。

Gemini、豆包、ChatGLM、腾讯元宝、Claude Cowork模式与Kimi Agent模式平台不支持分支，请选用轻装或全量书签。

## 二、安装与更新

### 自动安装：

1. 打开采云，进入"档案馆"。
2. 在左侧选择一个档位。需要多个档位时，分别选择并增量安装。
3. 选择 Chrome 用户和书签文件夹，默认"采云 Cloudig"。
4. 完全退出 Chrome，包括后台进程。
5. 安装单个平台，或安装全部选中平台。
6. 打开 Chrome，确认书签栏出现"采云 Cloudig"文件夹。
7. 点击全装按钮，会自动把当前所选的一类书签（轻装/全量/整树）都更新到最新版。

![书签名称包含平台、书签类型、版本。](assets/bookmark-guide/01-bookmarks-installed.png)

*图：书签名称包含平台、书签类型、版本。*

更新采云程序不会自动更新 Chrome 里的书签。请在退出Chrome后点击按钮更新书签。<br>
更新书签不会改变已下载的 HTML。

### 手动安装：

1. 点击平台右侧的复制按钮。
2. 右键Chrome书签栏，选择添加网页。
3. 输入名称，并且把刚才复制的代码内容完整粘贴在网址一栏。点击保存。

![手动安装书签示意图-01](assets/bookmark-guide/05-manual-add-page.png)

![手动安装书签示意图-02](assets/bookmark-guide/06-manual-paste-url.png)

可在Microsoft Edge书签栏手动安装书签使用。

## 三、会话导出

在已登录的平台上打开一篇具体会话，书签不支持设置页和空白首页。

1. 等正文和要保留的图片、图表、附件显示出来。
2. 点击对应平台的采云书签。
3. 看到"正在读取""正在保存资源"后，不要刷新、切换会话或再点书签。
4. 保持该标签选中、窗口可见，导出期间不操作这个窗口。
5. 书签报告完成、HTML 出现在下载列表后，可离开页面。

![导出进行中](assets/bookmark-guide/02-export-running.png)

*图：导出进行中。长会话、完整资源和整树需要更久。*

![下载完成](assets/bookmark-guide/03-download-complete.png)

*图：下载完成。*

书签可能滚动页面、展开面板来补齐内容。在这期间请不要刷新和操作此页面。

## 四、HTML 与采云

HTML 双击即可在浏览器打开，正文、样式、公式、静态图示和资源都在文件里，可离线阅读。<br>
内容中的外部链接在离线状态无法打开。

请保留原始 HTML：它既是档案，也是采云更新后重新解析的来源。

把 HTML 导入采云后，可以进一步获得：

- 不同平台档案的统一离线阅读与集中管理；
- 目录、平台和模型筛选；
- 标题、显示名称和身份设置；
- 内容时间设置；
- 后续持续增加的记录与阅读功能。

[平台范例入口](cloudig:platforms)

## 五、缺内容时

1. 先检查所使用的书签类型：轻装没有附件，图片是压缩格式、全量没有其他分支。
2. 刷新原会话，等内容加载，确认平台、档位、版本，重新导出并在下载完成之前不要操作页面，再检查新 HTML。惰性加载和临时资源地址常常让第二次导出成功。

在前两步后页面依然缺失内容，请打开档案馆或阅览室右侧导航栏中的系统日志：

1. 找到相应文件日志
2. 复制错误信息
3. 联系作者

有系统日志并不等于档案损坏或有内容缺失。<br>
请人工检查：<br>
HTML 能打开；对话轮次齐全、顺序正确；代码、公式、表格、图表、排版正常；图片和文件存在。

![系统日志的资源诊断](assets/bookmark-guide/04-system-log.png)

*图：系统日志的资源诊断。可以复制单条，也可以复制本文件全部错误并定位来源文件。删除日志不影响 HTML 和档案。*

## 六、四种更新

| 动作 | 改变什么 | 何时需要 |
|---|---|---|
| 更新采云程序 | Reader、Parser、档案馆、桌面功能 | 想用新功能 |
| 更新 Chrome 书签 | 以后从网页取内容的方式 | 新版修了你关心的平台问题 |
| 重新下载 HTML | 回网页重新取内容或文件 | 旧 HTML 内容缺失，且新书签已修复 |
| 在采云中重新解析 | 用新 Parser 从现有 HTML 生成新 JSON | HTML已有内容，但未被解析器正确解析 |

如果旧档案HTML已经内容完整、排版正常，即使书签更新也不必重新下载会话。

## 七、联系作者

请附：平台与入口（Chat、Cowork 等）；完整书签名称与数字版本；哪一轮、哪张图、哪个文件出了什么问题；问题位置截图；系统日志文本；去除不愿公开信息的HTML或官方Sharelink。

# Cloudig Bookmarklet Guide

Cloudig bookmarklets export AI conversations from websites as directly readable HTML.
Automatic installation in V1.0 supports Chrome only.

## The Shortest Possible Guide:

1. Close Chrome<br>
   Fully exit Chrome if you use Cloudig to automatically install, update or uninstall bookmarklets.
2. Choose a bookmarklet type and install it.<br>
   Use Light for everyday saves, Full for all attachments, and Tree for all branches.
3. Open an AI-platform conversation in Chrome.
4. Click the bookmarklet and wait for the export to finish.<br>
   Keep the exporting tab visible in the foreground and do not interact with the page until the HTML appears in the downloads list.
5. Check the HTML's text, formatting and files.
6. If text, images or files are missing:
   1. Check the bookmarklet version you used.<br>
      Light only exports page text and compressed images, not the text of user-uploaded attachments or files generated by AI.
   2. Refresh the page, choose the bookmarklet version you need and download again—network fluctuations and server conditions can sometimes cause missing content.

   If these two checks do not resolve the problem, open System Log in the Archiver's right sidebar, find and copy the relevant error, and contact the author with the version, log, screenshots and a sanitized page.
7. Keep the original HTML. It is the source for later reparsing in Cloudig.

## 1. Bookmarklet Types

| Bookmarklet type | Scope | Images and files |
|---|---|---|
| Light | Current branch | Compressed images; only names for other files |
| Full | Current branch | Original images and complete attachments |
| Tree | Complete message tree | Same as Full |

Use Light for everyday saves to save storage space;<br>
all three types can be installed together and used as needed.

Gemini, Doubao, ChatGLM, Tencent Yuanbao, Claude Cowork mode and Kimi Agent mode do not support branches. Use Light or Full bookmarklets.

## 2. Installation and Updates

### Automatic installation:

1. Open Cloudig and enter the Archiver.
2. Select one profile on the left. To install several profiles, install them one after another.
3. Select the Chrome profile and bookmark folder; the default is "采云 Cloudig".
4. Fully exit Chrome, including background processes.
5. Install one platform, or install all selected platforms.
6. Open Chrome and confirm that the "采云 Cloudig" folder appears in the bookmarks bar.
7. Click Install All to update every bookmarklet of the currently selected type (Light / Full / Tree) to the latest version.

![Bookmarklet names include the platform, type and version.](assets/bookmark-guide/01-bookmarks-installed.png)

*Figure: Bookmarklet names include the platform, type and version.*

Updating Cloudig does not automatically update the bookmarklets in Chrome. Exit Chrome, then click the button to update the bookmarklets.<br>
Updating bookmarklets does not change HTML already downloaded.

### Manual installation:

1. Click the copy button to the right of the platform.
2. Right-click the Chrome bookmarks bar and choose Add page.
3. Enter a name and paste the complete code you just copied into the URL field. Click Save.

![Manual bookmarklet installation—01](assets/bookmark-guide/05-manual-add-page.png)

![Manual bookmarklet installation—02](assets/bookmark-guide/06-manual-paste-url.png)

Bookmarklets can also be installed and used manually in the Microsoft Edge bookmarks bar.

## 3. Exporting a Conversation

Open a specific conversation on a platform where you are signed in. Bookmarklets do not support settings pages or empty homepages.

1. Wait for the text and the images, diagrams and attachments you want to keep to appear.
2. Click the Cloudig bookmarklet for that platform.
3. After you see "Reading" or "Saving resources", do not refresh, switch conversations or click the bookmarklet again.
4. Keep the tab selected and the window visible. Do not interact with this window during export.
5. Once the bookmarklet reports completion and the HTML appears in the downloads list, you can leave the page.

![Export in progress](assets/bookmark-guide/02-export-running.png)

*Figure: Export in progress. Long conversations, complete resources and Tree take longer.*

![Download complete](assets/bookmark-guide/03-download-complete.png)

*Figure: Download complete.*

The bookmarklet may scroll the page or expand panels to collect content. Do not refresh or interact with this page while it does so.

## 4. HTML and Cloudig

Double-click the HTML to open it in a browser. Its text, styles, formulas, static diagrams and resources are all in the file and can be read offline.<br>
External links in the content cannot be opened offline.

Keep the original HTML: it is both an archive and the source for reparsing after Cloudig is updated.

Importing HTML into Cloudig also gives you:

- Unified offline reading and centralized management of archives from different platforms;
- Folder, platform and model filters;
- Title, display-name and identity settings;
- Content-time settings;
- Further recording and reading features added over time.

## 5. When Content Is Missing

1. First check the bookmarklet type: Light has no attachments and uses compressed images; Full does not include other branches.
2. Refresh the original conversation, wait for content to load, confirm the platform, type and version, and export again without interacting with the page until the download finishes. Then check the new HTML. Lazy loading and temporary resource URLs often make a second export succeed.

If content is still missing after these two steps, open System Log in the right navigation sidebar of the Archiver or Reader:

1. Find the log for the relevant file.
2. Copy the error information.
3. Contact the author.

A system log does not by itself mean the archive is damaged or content is missing.<br>
Check manually:<br>
The HTML opens; conversation turns are complete and in the correct order; code, formulas, tables, diagrams and layout display correctly; images and files are present.

![Resource diagnostics in System Log](assets/bookmark-guide/04-system-log.png)

*Figure: Resource diagnostics in System Log. You can copy one entry, or copy all errors for this file and locate its source. Deleting logs does not affect the HTML or archive.*

## 6. Four Kinds of Update

| Action | What changes | When needed |
|---|---|---|
| Update Cloudig | Reader, Parser, Archiver and desktop features | You want new features |
| Update Chrome bookmarklets | How future content is collected from webpages | A new version fixes a platform issue that matters to you |
| Download the HTML again | Collect content or files from the webpage again | The old HTML is missing content and a new bookmarklet has fixed it |
| Reparse in Cloudig | Generate new JSON from existing HTML with the new Parser | Content is already in the HTML but was not parsed correctly |

If the old archived HTML is already complete and correctly formatted, a bookmarklet update does not require downloading the conversation again.

## 7. Contact the Author

Include: the platform and entry point (Chat, Cowork, etc.); the complete bookmarklet name and numeric version; which turn, image or file has which problem; screenshots of the problem; system-log text; and HTML with information you do not want public removed, or an official Share Link.

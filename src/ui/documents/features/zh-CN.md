# 采云 V1.0 功能与使用指南

采云 V1.0 支持将 AI 平台的云端对话采回本地，统一保存、整理和离线阅读，标记对话者的名称与对话内容的时间。采云也支持将对话导出成 Markdown 文件。

采云书签用于导出网页端的 AI 对话，生成可以直接阅读的 HTML；安装与使用见[《采云书签指南》](../01_书签指南/01_采云书签指南-GPT-5.6-Sol.md)。

未来版本中，采云将推出更丰富的对话管理功能。

## 极简使用方法

1. **用采云书签保存会话。** 在 AI 平台网页中打开一篇会话，点击书签栏中对应平台的采云书签，得到可以直接阅读的 HTML。Claude 也支持解析官方导出的 conversations.json。
2. **导入采云。** 打开采云，进入"档案馆"，点击"导入书签HTML"或"导入Claude JSON"；也可以点击"打开解析文件夹"，把文件直接放进去。
3. **解析。** 在来源文件所在行点击解析按钮，或点击"一键解析"。
4. **阅读。** 点击"开始阅览"进入阅览室，找到并打开这篇对话。
5. **按需整理。** 建立目录、修改标题与身份（Identity）、设置内容时间，或导出 Markdown。

| 想做什么 | 去哪里 |
|---|---|
| 安装与更新采云书签 | 档案馆左侧书签区，方法见[《采云书签指南》](../01_书签指南/01_采云书签指南-GPT-5.6-Sol.md) |
| 导入来源文件、解析、整理档案 | 档案馆 |
| 查找和阅读对话 | 阅览室 |
| 修改一篇对话的标题、模型与内容时间 | "编辑对话信息"，见 4.1 |
| 修改一篇对话里双方的身份 | 阅读时点击头像或名称，见 4.2 |
| 设置全局或各平台的身份 | 欢迎页或阅览室封面的相框，见 4.3 |
| 建立自己的时间轴 | 阅览室封面或档案馆的"内容时间轴"按钮，见 5.3 |
| 查看保存与解析中的问题 | 系统日志，见第七章 |

## 一、功能简介

### 1.1 档案馆和阅览室

**档案馆**负责导入来源文件、安装书签、解析和整理档案；**阅览室**负责查找和阅读已经解析好的对话。两边随时互相切换：档案馆右上角是"开始阅览"，阅览室右上角是"管理档案"。

### 1.2 来源、档案与你的修改

| 你看到的东西 | 是什么 | 文件目录 |
|---|---|---|
| 来源文件 | 书签下载的 HTML、Claude 官方导出的 conversations.json | Inbox |
| 对话档案 | 采云从来源解析出的对话 JSON | Conversations |
| 你的修改 | 你设置的标题、模型、身份和内容时间 | Marks |

在采云里修改标题、身份与内容时间时，采云会建立一份独立的 Mark.json 文件，不会修改解析后的对话档案或来源文件。

重新解析来源文件时，如果覆盖原对话档案，你已修改的标题、身份与内容时间不会被覆盖；如果生成新的对话档案，原来的修改不会同步到新档案中。

### 1.3 主题与语言

破晓与星夜只改变界面外观。中文与 English 切换界面语言和默认身份，不翻译对话正文，也不改动你自己设置的身份。

## 二、档案馆

### 2.1 界面总览

档案馆从左到右分为四个区域：

| 区域 | 用途 |
|---|---|
| 书签区 | 安装和更新采云书签，方法见[《采云书签指南》](../01_书签指南/01_采云书签指南-GPT-5.6-Sol.md) |
| 解析区 | 管理来源文件与解析 |
| 档案区 | 管理解析出的对话档案 |
| 功能导航区 | 打开各篇文档、系统日志和内容时间轴 |

标题栏显示当前资料库的位置："更改文件夹"用于整库搬家（见 6.3），"打开文件夹"在文件管理器中查看资料库。

![图02·档案馆全貌](assets/function-guide/02-archiver.png)

*图 2：左起依次为书签区、解析区、档案区和功能导航区。解析完成的文件会立即出现在档案区。*

### 2.2 导入来源文件

| 操作 | 结果 |
|---|---|
| "导入书签HTML" | 把 HTML 复制进 Inbox，原文件保留；与已有文件重名时自动改名保存，不覆盖 |
| "导入Claude JSON" | 把 conversations.json 复制进 Inbox，随后打开 Claude JSON 页面（见 2.5） |
| "打开解析文件夹" | 可以直接把需要解析的 HTML 与 JSON 文件复制到文件夹中 |
| 刷新 | 重新读取来源与档案的实际状态；在文件管理器中增删过文件后，请先刷新 |

每份 HTML 解析成一份独立档案；conversations.json 中的每条会话分别解析成独立档案。

### 2.3 解析单个文件

在来源文件所在行点击解析按钮（三角形），选择档案存放的目录。首次解析时，档案标题取自来源文件名（去掉扩展名）。

### 2.4 一键解析

点击"一键解析"旁的齿轮，设置解析后对话存放的目录，以及本次要解析的文件范围。范围由四个开关决定：

| 开关 | 默认 | 作用 |
|---|---|---|
| 解析所有未解析文件 | 开 | 解析还没有生成过档案的来源文件 |
| 解析或更新选中文件 | 开 | 解析或更新你在列表中选中的文件，包括已完成的 |
| 更新所有旧版解析文件 | 关 | 用新版解析器重新解析已经过时的旧结果 |
| 保留旧版解析结果 | 关 | 开启后，新结果另存为一份新档案；旧档案和你在它上面做过的修改原样保留 |

前三个开关共同圈定范围，同一个文件只会解析一次。Claude 的 conversations.json 不参与一键解析，请在 Claude JSON 页面中解析（见 2.5）。

点击"一键解析"后，采云会列出本次将要解析的文件、目标目录和更新方式。请确认无误后开始解析；需要调整时点击取消，回到设置修改。

*图 3：齿轮打开的一键解析设置。*

![图03b·一键解析确认](assets/function-guide/03b-batch-confirm.png)

*图 4：执行前的确认界面，列出本次范围、目标目录和更新方式。*

### 2.5 Claude JSON 页面

在解析区打开 conversations.json，进入 Claude JSON 页面。页面首次打开时建立索引，列出文件内的全部会话。

- 搜索框按标题查找会话；可按对话创建时间或更新时间排序，默认更新时间倒序。
- 点击会话条目，以图钉选中，可以多选。
- 单个解析与"一键解析"都可以选择或新建档案目录；"一键解析"默认解析全部未解析的会话，不需要先手动全选。

conversations.json 里逐条记录了模型名的消息，档案按记录显示；没有记录的消息显示为 Claude。

截至 2026 年 8 月，Claude 官方导出不包含 Cowork 会话。Cowork 会话请在网页中用 Claude 书签保存，方法见[《采云书签指南》](../01_书签指南/01_采云书签指南-GPT-5.6-Sol.md)。

![图04·Claude JSON页面](assets/function-guide/04-claude-json.png)

*图 5：标题搜索、时间排序、图钉多选与"一键解析"入口。*

### 2.6 解析状态与重试

来源列表可按状态查看：全部、待解析、已完成、失败、文件缺失、不支持。

- **失败**：点击重试按钮重新解析；鼠标移到失败标记上可以查看原因。文件本身不受支持导致的失败，会转为不支持。
- **已完成，带"解析器更新"提示**：这份档案使用的解析器已有新版，重新解析可以获得改进后的结果；不重新解析，旧档案照常阅读。某个平台的解析器更新，只影响该平台的档案。
- **文件缺失**：来源文件已不在 Inbox 中。点击条目上的删除按钮可以清除这条记录，也可以同时清除所有文件缺失条目。

"清除解析记录"只删除采云对"这个来源解析成了哪份档案"的记录，来源文件和已生成的档案都不受影响。

### 2.7 管理档案

档案区列出 Conversations 中的全部对话档案。

- **查找**：标题搜索、平台选择与目录选择；光锥按钮切换排序所依据的时间类别（种类见 3.1），排序按钮在时间倒序（茶壶）、时间顺序（时钟）与标题排序（花朵）之间切换。
- **目录**："新建目录"与"管理目录"对应 Conversations 文件夹内的实际子目录。
- **条目操作**：点击条目选中，出现图钉标记，可以多选；铅笔按钮打开"编辑对话信息"（见 4.1）。选中后，用上方按钮组"导出Markdown"（见 6.2）、"移动目录"、"归档"或"删除"。

归档把档案移入 Archives，退出日常列表；想再看时，在目录选择中打开归档目录。删除需要确认，档案与你的修改一起移入 Windows 回收站；Inbox 里的来源文件不受影响。

## 三、阅览室

### 3.1 找到一篇对话

阅览室封面左侧是目录侧边栏：

- 平台图标筛选平台，默认全选；
- 目录区选择一个或多个目录，"所有目录"查看全部；
- 搜索框按标题查找；
- 光锥按钮选择排序所依据的时间类别，排序按钮在时间倒序（茶壶）、时间顺序（时钟）与标题排序（花朵）之间切换。

可选的时间类别：JSON 修改时间、JSON 创建时间（即解析时间）、原文件采集时间、对话消息起点、对话消息终点、内容时间起点、内容时间终点。默认按 JSON 修改时间倒序。你的选择会被记住。

条目上的三点菜单提供编辑、移至目录、归档与删除。侧边栏可以折叠；折叠后保留上一篇、下一篇按钮。

![图05·阅览室封面](assets/function-guide/05-reader-cover.png)

*图 6：目录侧边栏从上到下依次是标题搜索、平台筛选、目录选择、时间类别与排序、对话列表。*

### 3.2 阅读一篇对话

对话页顶部显示标题、平台与模型标签、内容时间、导出时间和消息数；鼠标移到标题栏时，出现"导出Markdown"和"编辑"按钮。

一篇档案可以包含文字、Markdown 排版、代码、公式、图片、附件、引用来源、思考过程、工具调用、Schedule 任务和 Mermaid 等图表。采云按来源文件里实际保存的内容呈现：

| 内容 | 阅读时 |
|---|---|
| 代码 | 保留语言、缩进和语法排版，可以复制 |
| 公式 | 用保存的公式源码离线排版 |
| 图片与附件 | 保存了本体的可以离线查看；轻装只保存了元数据的附件，显示名称等信息 |
| 思考与工具调用 | 默认折叠，点击展开 |
| Mermaid 与图表 | 显示为图，可以切换查看源码 |
| Schedule | 显示任务卡片与取得的设置 |
| Box | 对话中的结构化卡片或轻量交互内容，如翻译、食谱、测验、图表和地点；按已保存的数据呈现 |
| Window | 点击“打开作品”后查看较大的作品；支持已接入的 HTML、React、Three.js、Chart.js，以及文档、幻灯片和设计类展示 |

重作品未打开时不运行，关闭后停止声音、动画与运行实例。轻量内嵌作品可放大、返回或收起；放大与返回不重启，收起会结束运行。作品中主动保存的本地进度只在本次采云运行中保留，普通内存状态不保证关窗后恢复；本版不提供持久保存。

地图卡片的地点与已保存照片可离线阅读。点击“加载地图”后才联网加载 OpenFreeMap 底图；地图可缩放、定位，关闭后释放。软件不附带地图包。

源码和资源保留在原对话中，阅读与操作不会改写原件。依赖未被本版接入的作品会说明无法运行，仍可查看已保存的源码。

![图06·阅读一篇对话](assets/function-guide/06-conversation.png)

*图 7：正文与思考、工具过程。用户发言带气泡，智能发言不带。*

### 3.3 分支

用整树（Tree）书签保存的档案，在真正发生分叉的消息处显示分支切换按钮，左右切换后沿所选路径连续阅读。轻装与全量只保存下载时显示的分支，没有分支按钮。

切换分支只影响本次阅读；重新打开对话时，回到保存的默认分支。

### 3.4 会话内搜索与阅读控制

- 工具栏搜索框在当前对话内查找，配合上一条、下一条按钮逐个定位，并显示"第 X 条 / 共 Y 条"。
- "展开思考与工具"与"隐藏思考与工具"控制过程内容的显示。
- 右侧导航栏按消息跳转："用户""智能""过程"决定导航列出哪些条目，过程默认不选；方向按钮在所选类型的消息之间跳转，也可以直达最前与最后一条。导航只改变跳转目标，不隐藏正文。
- 以上选择只在本次运行内有效，重新打开采云后恢复默认。
- 打开很长的对话时，会先显示标题和打开进度，请等待加载完成。

## 四、编辑：标题、模型与身份

### 4.1 编辑对话信息

三个入口，打开的是同一个页面：

- 档案馆档案条目的铅笔按钮；
- 阅览室封面条目三点菜单中的"编辑"；
- 阅读对话时标题栏的"编辑"按钮。

页面里可以修改：

- **对话标题**。标题与 JSON 文件名互相独立，改标题不会重命名文件。
- **模型标签**。可以删除，也可以添加。你添加的标签与来源里记录的模型分开保存；删除自己添加的标签后，恢复显示来源记录或平台名称。
- **内容时间**（见第五章）。

页面同时展示这篇对话的最后编辑时间、首次解析时间、对话消息时间、原文件名与原文件采集时间。修改完成后点击"保存"。

![图08·编辑对话信息](assets/function-guide/08-conversation-info.png)

*图 9：上半部分是标题、模型与时间信息，下半部分是内容时间编辑器。*

### 4.2 这一篇对话里的身份

阅读对话时，点击任意一条消息的头像或名称，打开身份编辑窗口。在这里修改的名称只用于当前这篇对话，优先于全局和平台设置；只能修改名称，不能为单篇对话单独设置头像。清空名称，即恢复原来的显示。

### 4.3 全局与各平台的身份

在欢迎页或阅览室封面点击"采云用户"或"智能伙伴"相框，打开全局名称与头像设置。

- **采云用户**：你在所有对话中显示的名称与头像。
- **智能伙伴**：全局默认的智能身份。勾选"所有对话使用统一智能头像与名字"后，全局设置覆盖所有平台设定；不勾选时，只作为未单独设置的平台的默认值。
- **十二平台**：ChatGPT、Claude、DeepSeek、Gemini、Grok、豆包、Kimi、Qwen、ChatGLM、Z.ai、腾讯元宝、Mistral 可以分别设置身份。

显示优先级从高到低依次为：这一篇对话里的身份，平台设置，全局智能伙伴，平台默认；勾选统一时，全局设置覆盖平台设置。名称与头像分别按此判断。"恢复默认"只清除对应的自定义值。头像文件缺失时显示默认头像，名称不受影响。

## 五、内容时间

内容时间标记这篇内容属于什么时候，由你来设定；它不是消息发送时间，也不是解析时间。例如 2026 年写下的秦史讨论，内容时间可以设为秦代。新档案默认没有内容时间。

内容时间分两类：**此地时间**以现实地球时间为主轴；**独立时间**由你自定义时间与意义。

### 5.1 给一篇对话设置时间

1. 打开"编辑对话信息"（见 4.1），进入内容时间编辑器。
2. 编辑起点：选择此地时间或独立时间，填写或选定后点击"确认时间"。
3. 终点默认"同起点"；需要时间段时点击编辑终点，选项与起点相同。
4. 确认无误后，点击页面底部的"保存"写入。

只设起点，就是一个时间点。起点晚于终点时，采云会提醒，仍然可以保存。

![图10·设置内容时间](assets/function-guide/10-content-time-edit.png)

*图 12：起点选项平铺展开；下方一行是终点与"确认时间"按钮。*

### 5.2 此地时间

起点和终点可以选择：

- **精确公历时间**：年月日，可以补充时分秒和时区；
- **模糊公历时间**：只到年、年月、年代或世纪；
- **亿万年前**：若干万年或若干亿年之前；
- **单位年后**：从万年后直到"正"年后（万的十次方年）；
- **特殊时间**：现今、无限久前、无限久后、不知何时、无论何时。

"现今"和"单位年前/后"在保存时记录当天日期作为锚点，之后不随打开日期变化。保存对话信息而没有改动内容时，采云会询问是否更新锚点。

编辑器里的九个预设标签——宇宙诞生、生命起源、史前文明、轴心时代、帝国兴亡、工业革命、硝烟铁幕、现代社会、智能初晓——点击即可填入对应时段。

### 5.3 建立自己的时间体系

点击阅览室封面或档案馆右侧的"内容时间轴"按钮，或从内容时间编辑器的"编辑时间轴"进入。封面左侧是此地时间轴，包含采云预设的时段，可以调整，不可删除；右侧是你建立的独立时间轴。

| 对象或动作 | 含义 |
|---|---|
| 时间轴 | 容器，有名称、作者和可选的版本号 |
| 单独时间 | 一个独立的时间节点 |
| 周期时间 | 重复出现的时间，有周期数，可选前缀和单位 |
| 包含 | 在时间中放入子时间，如一年包含十二个月；列表顺序即先后顺序 |
| 对映 | 让两个时间互为别名，如贞观元年对映 627 年 |
| 映射此地时间 | 把自建时间连接到现实的时间点或时间段 |
| 排序 | 调整顶层时间轴与时间的陈列顺序 |

映射到此地时间的自建时间，与此地时间一起排序；没有映射的独立排序。时间环、时间倒流、一个时间属于多条轴，都可以设定，采云不做限制；过大的周期数与复杂的循环映射可能影响性能。

*图 13：左侧此地时间轴，右侧独立时间轴，中间是时间体系说明与新建入口。*

![图11b·编辑时间](assets/function-guide/11b-time-editor.png)

*图 14：编辑一个时间：信息、引用它的对话、映射、对映与包含。*

### 5.4 修改已被引用的时间

编辑已被对话引用的时间或时间轴时，可以选择同步更新引用它的对话，或者另存为独立副本、旧时间保持不变。在"引用此时间的对话"列表中取消引用，会清空对应对话的内容时间；操作前会列出受影响的对话并要求确认。

## 六、导出、归档、删除与搬家

### 6.1 五个动作的区别

| 动作 | 结果 |
|---|---|
| 移动目录 | 档案在 Conversations 内换位置，其余一切不变 |
| 归档 | 档案移入 Archives，退出日常列表；随时可以从归档目录找回 |
| 删除 | 档案与你的修改一起进入 Windows 回收站；Inbox 来源文件保留 |
| 清除解析记录 | 只删除来源与档案的对应记录；来源文件和档案都保留 |
| 清空系统日志 | 只删除日志；来源、档案和你的修改都保留 |

### 6.2 导出 Markdown

在档案馆选中档案后点击"导出Markdown"，或在阅读对话时使用标题栏的"导出Markdown"。文件放入 Exports，导出完成后可以直接打开导出文件夹。

导出使用当前显示的标题、身份、模型和内容时间。整树档案导出当前正在阅读的分支。附件以来源里实际保存的为准：轻装来源没有附件本体，导出中也没有。

### 6.3 整库搬家

采云的全部数据都在一个文件夹里。换位置或换硬盘时，点击标题栏的"更改文件夹"，选择目标位置，确认后采云搬移完整目录，完成后从新位置继续使用。

请不要只复制 Cloudig.exe，也不要只移动其中某个子文件夹。

![图12·更改文件夹](assets/function-guide/12-move-library.png)

*图 15：选择目标位置并确认。搬家期间请不要关闭采云。*

### 6.4 备份与恢复

- 备份：退出采云，复制完整的采云文件夹，就是一份完整备份。
- 保存、删除或搬家中途断电、被强制关闭后，重新打开采云，会根据恢复记录给出恢复选择。
- 删除的档案在 Windows 回收站中，能否找回取决于回收站的当前状态。
- cache 文件夹可以在退出采云后删除；appdata 保存本机设置与恢复记录，请不要当作缓存清空。

## 七、系统日志

在档案馆或阅览室封面右侧点击"系统日志"，集中查看保存和解析过程中记录的问题。可以复制单条或整组信息、定位对应的来源文件、删除单组，或清空全部日志。

有日志不等于档案损坏。最终请以档案本身为准：对话能否打开、轮次是否齐全、排版是否正常、图片和文件是否符合所选书签类型。对话里 AI 自己说的"出错了"属于对话正文，不会出现在系统日志里。

同一来源重新解析后，对应的日志组会更新。需要反馈问题时，所需材料见[《采云书签指南》](../01_书签指南/01_采云书签指南-GPT-5.6-Sol.md)的"联系作者"。

![图13·系统日志](assets/function-guide/13-system-log.png)

*图 16：采云程序内的系统日志。删除日志不影响来源和档案。*

## 八、采云文件夹里有什么

日常使用不需要了解这些；备份、搬家或排查问题时用得上：

| 位置 | 存放内容 |
|---|---|
| Cloudig.exe | 采云程序入口 |
| CloudigLibrary.json | 资料库设置 |
| Inbox | 导入的来源文件 |
| Conversations | 对话档案，可以建子目录 |
| Marks | 你设置的标题、模型、身份与内容时间 |
| ContentTimes | 时间轴与时间节点 |
| Identities | 身份设置与自定义头像图片 |
| Archives | 已归档的对话 |
| Exports | 导出的 Markdown |
| appdata | 本机设置、解析记录、日志与恢复记录 |
| app、bookmarks、docs | 程序文件、随包书签与文档 |
| cache | 退出后可以删除的缓存 |

复制完整文件夹就是备份，整体移动就是搬家。各类记录的详细格式见[《采云标准》](../03_采云标准/03_采云标准-GPT-5.6-Sol.md)。
